# Spellwarden catalog fixture

A test fixture for the production checks of the Spellwarden curated catalog. It is a Claude Code plugin marketplace with one plugin, `claude-e2e-catalog`, holding one skill, `claude-e2e-catalog-skill`.

It exists so that Spellwarden can check installs, version updates, suspensions and alerts end to end without touching a real catalog entry. It is not meant to be installed or used.
